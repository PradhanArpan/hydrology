**Goal:** enter the storm recorded at the four teaching gauges into HEC-HMS: the recording gauge TG1 as a 30-minute series, and the non-recording gauges TG2–TG4 as storm totals.

**You need:** your project from L02, and the data files below. **Goes with:** Sessions 3–4. **Time:** about 35 minutes.

**Data:** [`U1_storm_TG1_30min.csv`](data/U1_storm_TG1_30min.csv) · [`U1_stations.csv`](data/U1_stations.csv)

| Gauge | Type | Storm data |
| --- | --- | --- |
| TG1 | recording (syphon) | 30-minute depths (mm): 2, 4, 7, 12, 18, 26, 14, 9, 6, 4, 2, 1 — total 105 |
| TG2 | non-recording | storm total 86 mm |
| TG3 | non-recording | storm total 124 mm |
| TG4 | non-recording (outside the catchment) | storm total 71 mm |

<!--step: Open the Time-Series Data Manager-->
1. Open your project `CE633_<RollNo>`.
2. <span class="menu">Components › Time-Series Data Manager</span>.
3. In the **Data Type** list choose **Precipitation Gages**.

> [!see] You should see
> A small manager window with buttons *New…*, *Copy…*, *Rename…*, *Delete*.

<!--step: Create gauge TG1-->
Click **New…**, name it `TG1`, description "Recording gauge, 30-min", **Create**. Close the manager.

In the Watershed Explorer expand **Time-Series Data › Precipitation Gages** and click `TG1`. In the Component Editor, **Time-Series Gage** tab, set:

| Field | Value |
| --- | --- |
| Data Source | Manual Entry |
| Units | **Incremental Millimeters** |
| Time Interval | **30 Minutes** |

<!--step: Set the time window-->
1. Expand `TG1`; it has a date node under it. Click it.
2. **Time Window** tab: Start Date `01Jan2000`, Start Time `00:00`; End Date `01Jan2000`, End Time `06:00`.

> [!note] Why 1 January 2000?
> The storm is teaching data with no real date. Any date works as long as the gauges, meteorologic model and control specifications all use the same one.

> [!see] You should see
> After setting the window, the **Table** tab shows 12 empty rows, ending 00:30, 01:00 … 06:00.

<!--step: Enter TG1's rain-->
1. Open the **Table** tab.
2. Type the 12 values in order: 2, 4, 7, 12, 18, 26, 14, 9, 6, 4, 2, 1. (Or copy the `TG1_incremental_mm` column from the CSV in a spreadsheet, click the first cell and paste with <kbd>Ctrl</kbd>+<kbd>V</kbd>.)
3. Open the **Graph** tab.

> [!see] You should see
> A hyetograph with a peak bar of 26 mm in the 02:30–03:00 interval — the same storm you analysed by hand in Session 7.

> [!fix] If the table has more or fewer rows
> The time window or interval is wrong. 6 hours ÷ 30 minutes must give 12 rows.

<!--step: Create TG2, TG3 and TG4-->
Repeat the steps for `TG2`, `TG3` and `TG4`, with these differences:

| Field | Value |
| --- | --- |
| Units | Incremental Millimeters |
| Time Interval | **6 Hours** |
| Time Window | `01Jan2000 00:00` to `01Jan2000 06:00` |
| Table | **one** value: TG2 = 86, TG3 = 124, TG4 = 71 |

> [!hms] Why a single 6-hour value?
> A non-recording gauge tells us only the storm total. In L05 the **Gage Weights** method takes the *depth* from all gauges and the *timing* only from the recording gauge TG1 — so one total per gauge is all HEC-HMS needs.

<!--step: Inspect the four gauges together-->
1. Open the Graph of each gauge in turn.
2. Ask the Session 4 question: is any total implausible compared with its neighbours?
3. Open `U1_stations.csv`: TG4 lies **outside** the catchment. Keep it anyway — Session 5 shows why.
4. <span class="menu">File › Save</span>.

<!--end-->
