**Goal:** apply the Thiessen weights from Session 5 inside HEC-HMS, compare them with an arithmetic mean, and see how areal averaging changes the flood.

**You need:** your project with TG1–TG4 (L03) and a working run (L04). **Goes with:** Session 5. **Time:** about 35 minutes.

| Gauge | Storm total (mm) | Thiessen weight | Arithmetic weight |
| --- | --- | --- | --- |
| TG1 | 105 | 0.428 | 0.333 |
| TG2 | 86 | 0.295 | 0.333 |
| TG3 | 124 | 0.242 | 0.333 |
| TG4 | 71 | 0.035 | 0 (outside) |

> [!hms] How Gage Weights works
> **Depth weights** decide *how much* rain falls on the subbasin (the areal average). **Time weights** decide *when* it falls — the pattern is borrowed from recording gauges. Here only TG1 records timing, so it gets time weight 1.

<!--step: Create the Thiessen meteorologic model-->
1. <span class="menu">Components › Create Component › Meteorologic Model</span>; name `Storm_Thiessen`.
2. **Precipitation = Gage Weights**. **Basins** tab: Include Subbasins = **Yes**.

<!--step: Select the gauges-->
1. Expand `Storm_Thiessen` › **Gage Weights** and click `Sub1`.
2. In the **Gage Selections** tab set **Use Gage = Yes** for TG1, TG2, TG3 and TG4.

> [!see] You should see
> The Depth Weights and Time Weights tabs now list the four gauges.

<!--step: Enter depth and time weights-->
1. **Depth Weights** tab: 0.428, 0.295, 0.242, 0.035.
2. **Time Weights** tab: TG1 = **1.0**, the others **0**.

> [!fix] Weights that do not add to 1
> HEC-HMS normalises the weights, but enter them correctly anyway — a typo such as 4.28 silently gives TG1 almost all the weight.

<!--step: Make the arithmetic version-->
1. Right-click `Storm_Thiessen` › **Save As…** (or use the Meteorologic Model Manager › Copy) and name the copy `Storm_Arithmetic`.
2. In its Gage Weights › Sub1 › **Depth Weights**: TG1, TG2, TG3 = 0.333, TG4 = 0.

<!--step: Create and compute two runs-->
1. Create `Run_Thiessen` (Teaching_Catchment, Storm_Thiessen, Day1) and `Run_Arith` (Teaching_Catchment, Storm_Arithmetic, Day1).
2. Compute both.

<!--step: Compare-->
1. Open the **Summary Table** of `Sub1` in each run and fill in:

| Run | Precipitation (mm) | Peak outflow (m³/s) | Volume (mm) |
| --- | --- | --- | --- |
| Run_Thiessen | | | |
| Run_Arith | | | |

2. To overlay the two hydrographs: in the **Results** tab, select `Sub1` under both runs (hold <kbd>Ctrl</kbd>) and open the graph — or use <span class="menu">Results › Compare</span> if your version has it.

> [!see] You should see
> Precipitation ≈ **102.8 mm** (Thiessen) and **105.0 mm** (arithmetic) — your hand answers from Session 5. With Loss = None the outflow volume differs by the same ≈ 2 %.

> [!hms] What to notice
> Once losses are added in Unit II, the same 2 % difference in rainfall produces a **larger** percentage difference in runoff, because losses are taken off the top. That is why areal averaging matters.
