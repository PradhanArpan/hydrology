**Goal:** build Thiessen polygons for the teaching catchment in QGIS from real coordinates, compute the weights, and print a map.

**You need:** QGIS (Long Term Release) installed. **Goes with:** Sessions 5 and 9. **Time:** about 45 minutes.

**Data:** [`U1_stations.csv`](data/U1_stations.csv) (gauges, longitude/latitude, storm totals) · [`U1_catchment.geojson`](data/U1_catchment.geojson) (catchment boundary). These are synthetic teaching data placed near Kengeri.

<!--step: Start a project in a metric CRS-->
1. Open QGIS › **New Project**.
2. Bottom-right corner: click the CRS button (shows `EPSG:4326`), search **32643** and choose **WGS 84 / UTM zone 43N**. OK.

> [!note] Why UTM 43N?
> Areas must be computed in metres, not degrees. Karnataka lies in UTM zone 43N (EPSG:32643).

<!--step: Add a basemap-->
In the **Browser** panel expand **XYZ Tiles** and double-click **OpenStreetMap**. Zoom to Bengaluru. (The basemap is for orientation only.)

<!--step: Load the gauges from the CSV-->
1. <span class="menu">Layer › Add Layer › Add Delimited Text Layer</span>.
2. File: `U1_stations.csv`. Geometry: **Point coordinates**, X field = `lon`, Y field = `lat`, Geometry CRS = **EPSG:4326**.
3. **Add**, then close the dialog.

> [!see] You should see
> Four points west of Bengaluru near Kengeri. Right-click the layer › *Zoom to Layer*.

> [!fix] Points appear off the coast of Africa
> X and Y were swapped, or the CRS was not EPSG:4326. Remove the layer and add it again.

<!--step: Load the catchment-->
Drag `U1_catchment.geojson` from your file manager onto the map. Style it with no fill and a thick blue outline (double-click the layer › Symbology).

<!--step: Reproject both layers-->
<span class="menu">Vector › Data Management Tools › Reproject Layer</span> — input the stations layer, target CRS **EPSG:32643**, Run. Do the same for the catchment. Work with the two **Reprojected** layers from now on (you can rename them `stations_utm` and `catchment_utm`).

<!--step: Build Voronoi polygons-->
<span class="menu">Vector › Geometry Tools › Voronoi Polygons</span>: input `stations_utm`, **Buffer region = 50 %**, Run.

> [!see] You should see
> Four polygons around the four gauges, extending well beyond the catchment. Each polygon carries its gauge's attributes.

<!--step: Clip to the catchment-->
<span class="menu">Vector › Geoprocessing Tools › Clip</span>: input = Voronoi polygons, overlay = `catchment_utm`, Run. Name the output `thiessen`.

<!--step: Compute areas and weights-->
1. Open the attribute table of `thiessen` (right-click › Open Attribute Table) and toggle editing (pencil icon).
2. Open the **Field Calculator** (abacus icon) and create three decimal fields:
   - `area_km2` = `$area / 1e6`
   - `weight` = `"area_km2" / sum("area_km2")`
   - `wP` = `"weight" * "storm_total_mm"`
3. Save edits.
4. Select the `thiessen` layer and open <span class="menu">View › Statistical Summary</span> (Σ icon); choose the field `wP` — its **Sum** is the Thiessen mean.

> [!see] You should see
> Weights close to **0.428** (TG1), **0.295** (TG2), **0.242** (TG3), **0.035** (TG4); total area ≈ 54.85 km²; Thiessen mean ≈ **102.8 mm** — the values you used in HEC-HMS (L05). Differences under 1 % come from the projection.

<!--step: Label and print a map-->
1. Label the polygons with the weight: Layer Properties › Labels › Single Labels › Value = `round("weight",3)`.
2. <span class="menu">Project › New Print Layout</span>: add the map, a legend, a scale bar, a north arrow and a title.
3. Export as PDF.
