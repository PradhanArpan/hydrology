**Goal:** create the HEC-HMS project you will keep all semester, and draw the 54.85 km² teaching catchment as one subbasin draining to an outlet.

**You need:** HEC-HMS installed (L01). **Goes with:** Session 3. **Time:** about 30 minutes.

> [!note] One model, all semester
> The project you create today grows every week: gauges (L03), a first run (L04), areal rainfall (L05–L06), design storms (L08), then losses in Unit II, unit hydrographs in Unit III and routing in Unit IV. Keep it safe and back it up.

<!--step: Create a new project-->
1. <span class="menu">File › New</span>.
2. **Name:** `CE633_<RollNo>` (no spaces). **Description:** "CE633 course model". **Location:** your `Documents/CE633/` folder.
3. **Default Unit System: Metric.** This matters — changing it later is painful.
4. Click **Create**.

> [!see] You should see
> An empty Watershed Explorer with the project name at the top, and a folder `CE633_<RollNo>` created on disk.

> [!fix] If you chose U.S. Customary by mistake
> Close the project, delete its folder and start again — it takes a minute now and saves hours later.

<!--step: Create the basin model-->
1. <span class="menu">Components › Create Component › Basin Model</span>.
2. Name it `Teaching_Catchment` and click **Create**.
3. Expand **Basin Models** in the Watershed Explorer and click `Teaching_Catchment`.

> [!see] You should see
> An empty map on the Desktop titled *Basin Model [Teaching_Catchment]*, and the element-creation buttons in the toolbar become active.

<!--step: Add the subbasin-->
1. In the toolbar choose the **Subbasin Creation Tool** (hover over the buttons to read their names).
2. Click once in the middle of the map. Name the element `Sub1`.
3. Select `Sub1` (click it with the arrow tool). In the **Component Editor › Subbasin** tab type **Area = 54.85** (km²).

> [!hms] Why one subbasin?
> We start with the whole catchment as one lumped unit. In L10 you will let HEC-HMS split a real catchment into several subbasins from a DEM.

<!--step: Choose temporary methods-->
Still in the Subbasin tab (scroll down — Discretization, Canopy, Snow and Surface come first, then Loss, Transform and Baseflow; compare the Castro screenshot in L01), set:

| Field | Value | Why for now |
| --- | --- | --- |
| Discretization, Snow | None | not used in this course |
| Canopy | None | studied in Unit II |
| Surface | None | studied in Unit II |
| Loss Method | **None** | all rain becomes runoff, so volumes are easy to check |
| Transform Method | **SCS Unit Hydrograph** | needed so the model can produce a hydrograph (Unit III) |
| Baseflow Method | None | Unit III |

Then open the **Transform** tab and set **Lag Time = 90** (minutes); leave the graph type as *Standard*.

> [!see] You should see
> The Subbasin tab shows Area 54.85 and the chosen methods; the Transform tab shows a lag-time box.

<!--step: Add the outlet and connect it-->
1. Choose the **Sink Creation Tool** and click below the subbasin. Name it `Outlet`.
2. Select `Sub1` again and set **Downstream = Outlet** in its Subbasin tab.

> [!see] You should see
> A line connecting `Sub1` to `Outlet` on the map. No line means the downstream connection was not set.

<!--step: Save and back up-->
1. <span class="menu">File › Save</span>.
2. Close HEC-HMS, zip the whole `CE633_<RollNo>` folder and keep a copy in Google Drive. **Always zip the whole folder** — an HMS project is many files, not one.

<!--end-->
