**Goal:** get real IMD rainfall for a place you know, check it, fill the gaps and test it for consistency — the same steps an engineer goes through before using rainfall for design.

**You need:** a Google account (for Colab) or Python 3, and a spreadsheet. **Goes with:** Sessions 4 and 6. **Time:** about 60 minutes (part at home).

> [!note] Where real Indian rainfall data comes from
> | Source | What you get | Cost and access |
> | --- | --- | --- |
> | **IMD gridded rainfall, 0.25°** (Pai et al. 2014), from [IMD Pune](https://imdpune.gov.in) | Daily rainfall on a ≈28 km grid, built from about 6,955 gauges, 1901 to last year | Free download; easiest with the Python package **[imdlib](https://imdlib.readthedocs.io/en/latest/Usage.html)** |
> | **IMD station data** — Meteorological Centre Bengaluru ([procedure](https://mausamaudit.imd.gov.in/bengaluru/docs/data-procedure.pdf), [request form](https://mausamaudit.imd.gov.in/bengaluru/docs/data-request.pdf)) | Daily/hourly records of named stations, exactly as observed | Paid. Apply with the form and a letter from your guide; IMD sends a quote; payment through Bharat Kosh. Large older requests go to the [IMD Data Supply Portal](http://dsp.imdpune.gov.in), Pune |
> | **[India Precipitation, daily, 1901–1970](https://gdex.ucar.edu/datasets/d480000/)** (NCAR archive of IMD records) | Daily rainfall at 1,600–2,500 Indian stations | Free (CC BY 4.0) — real station records, good for consistency tests |
> | **[data.gov.in — IMD daily rainfall](https://www.data.gov.in/resource/daily-rainfall-data-india-meteorological-department-imd-grid-model-agency-during-725)** | District- and state-level daily rainfall | Free download (CSV) |
> | **KSNDMC** (Karnataka) and **India-WRIS** | Automatic rain-gauge and basin rainfall for Karnataka / India | Free to view on their portals |

> [!warn] Gridded is not the same as a gauge
> A grid value is an interpolation of many gauges, so it is smoother than any one gauge and rarely shows the sudden breaks that a shifted gauge produces. We use it today because it is free and complete. For a project or thesis, request the station record from IMD.

The script downloads one file per year (about 4 MB each, so give it a few minutes). It then takes the grid cell at your location as **station X** and five neighbouring cells, about 28 km away, as **base stations A–E**.

> [!see] You should see
> Two new files, `daily_rain.csv` and `annual_rain.csv`, and a line giving the mean annual rainfall at X. For Bengaluru, expect a value in the region of 800–1,000 mm.

> The IMD server is sometimes slow. Run the cell again — files already downloaded are skipped. If it still fails, use the NCAR or data.gov.in source in the table above, or the course data set from Session 4.

<!--step: Fill a missing year (Session 6)-->
If a year is blank (or, for practice, delete the 2005 value of X yourself):

1. Compute the **normal annual rainfall** $N$ of each station: the mean of all complete years.
2. If every $N_i$ is within 10 % of $N_x$, use the **arithmetic mean** of A–E for that year.
3. Otherwise use the **normal-ratio method**:

$$P_x = \frac{N_x}{M}\left(\frac{P_A}{N_A} + \frac{P_B}{N_B} + \dots\right)$$

with $M$ = the number of base stations used.

:::task Check
Compare your estimate for 2005 with the value you deleted. What is the percentage error? Which method was closer?
:::

<!--step: Test consistency with the double mass curve (Session 4)-->
1. In the spreadsheet, add a column for the **mean of A–E** each year.
2. Accumulate X and the base mean year by year, and plot ΣX against Σbase.
3. Or: open the **[Double mass curve](#/s/S04)** tool in Session 4, choose **Paste your data**, and paste `annual_rain.csv`. Work through the six steps.

> [!see] You should see
> A nearly straight line — the gridded record is consistent, as expected.

<!--step: Simulate a shifted gauge and correct it-->
Now make the record inconsistent on purpose, the way a gauge relocation would:

1. Multiply every value of X from **2008** onwards by **1.15** (the "new site" catches 15 % more).
2. Repeat the double mass curve. Find the break and the two slopes $M_a$ and $M_c$.
3. Correct the 2008–2020 values with $P_{cx} = P_x\,M_a/M_c$.

:::sol What you should find
The break appears at 2007/2008. The slope ratio $M_a/M_c$ comes out close to $1/1.15 = 0.87$ — not exactly, because the base stations' rainfall varies from year to year. The corrected values should be within a few per cent of the original ones.
:::
