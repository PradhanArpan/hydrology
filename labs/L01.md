> [!note] New to HEC-HMS?
> Read **[About HEC-HMS](#/sw/hms)** first (10 minutes): what the program does, how a model is organised, and a clickable tour of the window.

**Goal:** install HEC-HMS, run a complete model that someone else built, and learn where each part of the hydrologic cycle lives inside it. You will not build anything yet.

**You need:** a laptop (Windows, macOS or Linux) with about 1 GB free, and an internet connection for the download.
**Do it:** install at home after Session 1; the model tour is done in class in Session 2.

::widget[hmstour]

<!--step: Download HEC-HMS-->
1. Open the **HEC-HMS download** link in the sidebar (Quick links). It is the US Army Corps of Engineers Hydrologic Engineering Center site, ending in `.army.mil`.
2. Download the **latest 4.x installer** for your operating system. Do not use installers from other websites.

> [!see] You should see
> A file of a few hundred MB, e.g. `HEC-HMS_4.xx_Windows.exe`, or a `.dmg` / `.tar.gz` for Mac / Linux.

<!--step: Install and start it-->
1. Run the installer and accept the defaults.
2. **Windows:** start HEC-HMS from the Start menu or the desktop shortcut. **macOS:** drag it to Applications; the first time, right-click the app › *Open* (macOS blocks unsigned apps on a double-click). **Linux:** unpack and run the `hec-hms.sh` script.

> [!see] You should see
> The HEC-HMS window: a menu bar (File, Edit, View, **Components**, **GIS**, Parameters, **Compute**, **Results**, Tools, Help), two rows of toolbar buttons, an empty panel on the left and a grey desktop on the right. The version number is in the title bar.

![HEC-HMS 4.14 just after starting — no project open yet — Screenshot, HEC-HMS 4.14](assets/img/labs/L01_01_empty_window.png)

> [!fix] If it does not start
> On Windows, right-click › *Run as administrator* once. On a university laptop, ask IT to allow the installer. Note the exact error message and post it in Google Classroom.

<!--step: Make a working folder-->
Create a folder for the whole semester, for example `Documents/CE633/Software/`. The sample projects and every HMS project you create in this course go in there.

Keep project **names** short and without spaces (`CE633_Roll123`, not `My CE633 project (final)`). Folder paths with spaces work, but short simple names avoid trouble when you zip and submit projects.

<!--step: Install the sample projects-->
1. Choose <span class="menu">Help › Install Sample Projects…</span>
2. When asked for a location, choose your `CE633/Software` folder and confirm.

![The Help menu of HEC-HMS 4.14 — Screenshot](assets/img/labs/L01_02_help_install_samples.png)

<!--step: Read the basin map-->
1. Expand **Basin Models** (click the ⊞ box) and click **Castro 1**. The basin map opens on the desktop. Maximise the HEC-HMS window — the map needs space.
2. In the tree under Castro 1 you will see every element: **Subbasin-1 … Subbasin-4**, **Reach-1**, **Reach-2**, the junctions **West Branch** and **East Branch**, and the sink **Outlet**. The icons match the map: subbasins (drop and arrow), reaches (channel), junctions and the outlet.
3. Click **Subbasin-3** in the tree. The **Component Editor** shows its **Subbasin** tab.

![Castro 1 basin model with Subbasin-3 selected — Screenshot, HEC-HMS 4.14 (sample project)](assets/img/labs/L01_08_castro_basin_subbasin.png)

> [!see] You should see
> Basin Name **Castro 1**, Element Name **Subbasin-3**, Downstream **Reach-2**, **Area (MI2) 2.17** — and methods for Discretization, Canopy, Snow and Surface (all *None* here). The Message Log at the bottom reports that the project was opened.

> [!warn] Units
> The Castro Valley sample is in **U.S. customary units**: area in square miles (MI2), depths in inches (IN), flows in cfs. 2.17 mi² ≈ 5.62 km². Your own course project (Lab L02) is created in **Metric** units.

<!--step: Look inside the subbasin: Loss, Transform, Baseflow-->
With Subbasin-3 still selected, open the next three tabs of the Component Editor and note the values.

| Tab | Method in Castro 1 | Parameters (Subbasin-3) | Hydrologic process | Studied in |
| --- | --- | --- | --- | --- |
| **Loss** | Initial and Constant | Initial loss 0.02 in · Constant rate 0.14 in/h · Impervious 10 % | Infiltration (φ-index idea) | S12–S13 |
| **Transform** | Snyder unit hydrograph (Standard) | Standard lag 0.2 h · Peaking coefficient 0.16 | Overland flow → hydrograph | S23–S27 |
| **Baseflow** | Recession | Initial discharge 0.54 cfs/mi² · Recession constant 0.79 · Threshold: ratio to peak 0.1 | Groundwater return flow | S21 |

> [!hms] Link to theory
> Each tab is one arrow of Horton's engineering representation (Session 1): **Loss** = infiltration, **Transform** = overland flow to the stream, **Baseflow** = groundwater return flow. The red asterisk (*) marks parameters the model needs before it will run.

<!--step: Read the meteorologic model-->
1. In the tree expand **Meteorologic Models** and click the meteorologic model. In the Component Editor note the **Precipitation** method.
2. Expand it and find which gauge (or storm) supplies rain to each subbasin. Then expand **Time-Series Data › Precipitation Gages** to see the gauges themselves.

> [!see] You should see
> A precipitation method (e.g. *Specified Hyetograph* or *Gage Weights*) and the gauge(s) assigned to each subbasin. This is where rainfall data enter the model — Sessions 3–8 build exactly this part.

<!--step: Run a simulation-->
1. Click the **Compute** tab at the bottom of the Watershed Explorer.
2. Expand **Simulation Runs** and select the first run.
3. Click the **Compute Current Run** button in the toolbar (or right-click the run › *Compute*).

> [!see] You should see
> A progress window, then a line in the **Message Log** (part 6) saying the run finished. Notes in black or green are fine; **ERROR** lines in red mean it did not run.

> [!fix] If it fails
> Read the red ERROR line — it names the element and the problem. For the sample project the usual cause is opening it from a zip or read-only folder: copy the `castro` folder into `Documents/CE633/` and open it from there.

<!--step: Look at the results-->
1. Click the **Results** tab (bottom of the Watershed Explorer). Expand the run, then a **subbasin**, and open **Graph**.
2. Then open the **Summary Table** of the **outlet** (sink).

> [!see] You should see
> In the graph: rainfall as bars at the top (the hyetograph) and the outflow hydrograph below. In the summary table: **peak discharge**, **time of peak** and **outflow volume**.

| Hydrologic-cycle process | Where it lives in HEC-HMS | In Castro Valley |

| Interception, depression storage | Subbasin › Canopy and Surface methods | |
| Infiltration (loss) | Subbasin › Loss method | |
| Overland flow to the stream | Subbasin › Transform method | |
