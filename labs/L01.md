**Goal:** install HEC-HMS, run a complete model that someone else built, and learn where each part of the hydrologic cycle lives inside it. You will not build anything yet.

**You need:** a laptop (Windows, macOS or Linux) with about 1 GB free, and an internet connection for the download.
**Do it:** install at home after Session 1; the model tour is done in class in Session 2.

![The HEC-HMS window and its six parts — Schematic drawn for this course; your version may differ slightly](assets/img/labs/hms_window.svg)

<!--step: Download HEC-HMS-->
1. Open the **HEC-HMS download** link in the sidebar (Quick links). It is the US Army Corps of Engineers Hydrologic Engineering Center site, ending in `.army.mil`.
2. Download the **latest 4.x installer** for your operating system. Do not use installers from other websites.

> [!see] You should see
> A file of a few hundred MB, e.g. `HEC-HMS_4.xx_Windows.exe`, or a `.dmg` / `.tar.gz` for Mac / Linux.

<!--step: Install and start it-->
1. Run the installer and accept the defaults.
2. **Windows:** start HEC-HMS from the Start menu. **macOS:** drag it to Applications; the first time, right-click the app › *Open* (macOS blocks unsigned apps on a double-click). **Linux:** unpack and run the `hec-hms.sh` script.

> [!see] You should see
> The HEC-HMS window with an empty grey desktop, a menu bar (File, Edit, View, **Components**, **GIS**, Parameters, **Compute**, **Results**, Tools, Help) and an empty Watershed Explorer on the left — compare with the schematic above.

> [!fix] If it does not start
> On Windows, right-click › *Run as administrator* once. On a university laptop, ask IT to allow the installer. Note the exact error message and post it in Google Classroom.

<!--step: Install the sample projects-->
1. Choose <span class="menu">Help › Install Sample Projects</span>.
2. Accept the default folder (inside your Documents folder) and click **Install**.

> [!see] You should see
> A confirmation that several sample projects were installed, including **Castro Valley** (folder `castro`), **Tenk** and others.

<!--step: Make a working folder-->
Create a folder for the whole semester, for example `Documents/CE633/`. Every HMS project you create in this course goes in there. **Avoid spaces and special characters** in folder and project names — use `CE633_Roll123`, not `My CE633 project (final)`.

<!--step: Open the Castro Valley project-->
1. <span class="menu">File › Open</span>, browse to the sample-projects folder › `castro` › the `.hms` file, and open it.
2. Look at the **Watershed Explorer** (part 3 in the schematic). Click the small triangles to expand each folder.

> [!see] You should see
> Folders for **Basin Models**, **Meteorologic Models**, **Control Specifications** and **Time-Series Data** (gauges). Every HMS simulation is built from one of each of the first three.

<!--step: Read the basin map-->
1. Click the basin model (e.g. *Castro 1*). The **Desktop** shows a map.
2. Identify the element types by their icons: **subbasins** (areas that produce runoff), **reaches** (channels that carry it), **junctions** (where flows join) and a **sink** (the outlet).
3. Click one subbasin. In the **Component Editor** (part 4), note its **Area** and the methods chosen for **Loss**, **Transform** and **Baseflow**.

> [!hms] Link to theory
> Each of those methods is one arrow of Horton's engineering representation (Session 1): loss = infiltration, transform = overland flow to the stream, baseflow = groundwater return flow.

<!--step: Read the meteorologic model-->
1. Click the meteorologic model. In the Component Editor note the **Precipitation** method.
2. Expand the met model in the Watershed Explorer and find which gauge (or storm) supplies rain to each subbasin.

> [!see] You should see
> A precipitation method such as *Specified Hyetograph* or *Gage Weights*, and gauge names under it. This is where rainfall data enter the model — Sessions 3–8 build exactly this part.

<!--step: Run a simulation-->
1. Click the **Compute** tab at the top of the Watershed Explorer.
2. Expand **Simulation Runs** and select the first run.
3. Click the **Compute Current Run** button in the toolbar (or right-click the run › *Compute*).

> [!see] You should see
> A progress window, then a line in the **Message Log** (part 6) saying the run finished. Notes in black or green are fine; **ERROR** lines in red mean it did not run.

> [!fix] If it fails
> Read the red ERROR line — it names the element and the problem. For the sample project the usual cause is opening it from a zip or read-only folder: copy the `castro` folder into `Documents/CE633/` and open it from there.

<!--step: Look at the results-->
1. Click the **Results** tab. Expand the run, then a **subbasin**, and open **Graph**.
2. Then open the **Summary Table** of the **outlet** (sink).

> [!see] You should see
> In the graph: rainfall as bars at the top (the hyetograph) and the outflow hydrograph below. In the summary table: **peak discharge**, **time of peak** and **outflow volume**.
