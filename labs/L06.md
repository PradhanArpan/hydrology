**Goal:** see what a missing value does inside HEC-HMS, and run the model with a gap filled by the normal-ratio method.

**You need:** `Storm_Thiessen` and `Run_Thiessen` from L05. **Goes with:** Session 6. **Time:** about 30 minutes.

**Scenario:** TG3's observer missed the reading. Your normal-ratio estimate from Session 6 is **112.4 mm** (the true value was 124 mm).

<!--step: Make a gauge with the estimate-->
1. Right-click `TG3` › **Save As…** (or Time-Series Data Manager › Copy) and name the copy `TG3_est`.
2. In its Table change the single value to **112.4**.

<!--step: Make a met model that uses it-->
1. Copy `Storm_Thiessen` to `Storm_Thiessen_est`.
2. In its Gage Weights › Sub1: **Gage Selections** TG3 = No, TG3_est = Yes; **Depth Weights** TG3_est = 0.242 (others unchanged); **Time Weights** TG1 = 1.

<!--step: Run and compare-->
Create and compute `Run_TG3est`. Compare its `Sub1` precipitation and peak with `Run_Thiessen`.

> [!see] You should see
> Precipitation ≈ **100.0 mm** instead of 102.8 mm — about 3 % less, because the estimate is 11.6 mm below the true TG3 value and TG3 carries 24 % of the weight.

<!--step: Create a gap in the recording gauge-->
1. Copy `TG1` to `TG1_gap`.
2. In its Table, **delete** the value at **03:00** (the 26 mm peak) so the cell is empty.
3. Copy `Storm_Thiessen` to `Storm_gap` and make it use `TG1_gap` instead of `TG1` (both in Gage Selections and as the time-weight gauge).

<!--step: Run it and read the Message Log-->
Create and compute `Run_gap`. Read every line the Message Log prints.

> [!see] You should see
> Either an error that stops the run because of missing data, or a warning that missing values were replaced.

<!--step: Try the Replace Missing option-->
1. Click `Storm_gap`. In the Component Editor find the **Replace Missing** option (it is in the meteorologic model's main tab for most precipitation methods).
2. Set it to **Set To Default** and run again. Then compare the precipitation total and peak with `Run_Thiessen`.

> [!hms] What to notice
> "Default" means **zero rain** in the gap. A missing 26 mm peak silently becomes a dry half-hour: the storm total falls by a quarter and the flood peak falls even more. HEC-HMS will not fill a gap with a hydrologically sensible value — that is the hydrologist's job, done *before* the data go in.
