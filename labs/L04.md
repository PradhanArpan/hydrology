**Goal:** run the model for the first time — rainfall from TG1 on the whole subbasin — and read the results.

**You need:** your project with `Sub1`, `Outlet` (L02) and gauge `TG1` (L03). **Goes with:** Session 3. **Time:** about 35 minutes.

<!--step: Create a meteorologic model-->
1. <span class="menu">Components › Create Component › Meteorologic Model</span>; name `Storm_TG1`.
2. Click it. In the Component Editor (Meteorology Model tab) set **Precipitation = Specified Hyetograph**. Leave the other methods as *None*.
3. Open the **Basins** tab and set **Include Subbasins = Yes** for `Teaching_Catchment`.

> [!fix] Forgot step 3?
> The run will fail with a message that the meteorologic model has no subbasins. Every new met model must be told which basin models it serves.

<!--step: Link the subbasin to the gauge-->
1. In the Watershed Explorer expand `Storm_TG1` › **Specified Hyetograph** and click `Sub1`.
2. Set **Gage = TG1**.

> [!see] You should see
> `Sub1` listed under Specified Hyetograph, with TG1 selected — meaning "the rain on Sub1 is exactly the TG1 record".

<!--step: Create control specifications-->
1. <span class="menu">Components › Create Component › Control Specifications</span>; name `Day1`.
2. Start `01Jan2000` `00:00`; End `02Jan2000` `00:00`; **Time Interval 15 Minutes**.

> [!hms] Why run 24 hours for a 6-hour storm?
> Runoff keeps arriving at the outlet long after the rain stops. The run must be long enough for the hydrograph to return to (nearly) zero, or the volume check in step 6 will not balance.

<!--step: Create the simulation run-->
1. <span class="menu">Compute › Create Compute › Simulation Run</span>.
2. Name `Run_S03`, then choose basin `Teaching_Catchment`, met model `Storm_TG1` and control `Day1` in the wizard pages. **Finish**.

<!--step: Compute-->
1. In the **Compute** tab of the Watershed Explorer select `Run_S03`.
2. Click **Compute Current Run** in the toolbar (or right-click › *Compute*).

> [!see] You should see
> The Message Log ends with a note that `Run_S03` finished. No red ERROR lines.

<!--step: Read and check the results-->
1. **Results** tab › `Run_S03` › `Sub1` › **Graph**: rain bars on top, outflow hydrograph below.
2. Open the **Summary Table** for `Outlet`: note **peak discharge (m³/s)**, **time of peak** and **outflow volume**.
3. Check the volume by hand: with Loss = None, all rain becomes runoff, so volume = 105 mm × 54.85 km² = **5.76 × 10⁶ m³** (HEC-HMS may report it as a depth, 105 mm, or in 1000 m³).

> [!fix] If the volume is less than 105 mm
> The hydrograph had not finished by the end time — extend the control end time to `02Jan2000 12:00` and recompute.

<!--step: Change one thing and re-run-->
Change the **Lag Time** of `Sub1` from 90 to **45** minutes, recompute, and compare peak and time of peak. Then set it back to 90.

> [!hms] What to notice
> A shorter lag gives a higher, earlier peak but **the same volume** — the transform moves water in time; it does not create or destroy it. You will meet lag time properly in Unit III.
