## What to install, and when

| Software | Needed from | Platforms | Cost |
| --- | --- | --- | --- |
| **HEC-HMS** (Hydrologic Modeling System), latest 4.x | Lab L01, before Session 2 | Windows, macOS, Linux | Free (US Army Corps of Engineers) |
| **QGIS**, current Long Term Release | Lab L09 (Session 9) | Windows, macOS, Linux | Free, open source |
| **HEC-RAS** (River Analysis System), latest 6.x | Session 28 | **Windows only** | Free |
| **HEC-SSP** (Statistical Software Package) | Session 35 | Windows | Free |
| Excel or Google Sheets | Session 1 | Any | — |

All three HEC programs are published by the **Hydrologic Engineering Center** (HEC) of the US Army Corps of Engineers. Download them only from the HEC website (search "HEC-HMS download" — the official site ends in `.army.mil`). Do not use repackaged installers from other sites.

## HEC-HMS

:::steps
1. Download the installer for your operating system from the HEC-HMS downloads page.
2. Install with default options. On macOS, if the app is blocked, open it once with right-click › *Open*.
3. Start HEC-HMS. Use **Help › Install Sample Projects** and accept the default folder.
4. Open the *Castro Valley* sample (File › Open) and check that a simulation run computes without errors. If it does, you are ready for Session 2.
:::

> [!hms] Menu names
> Lab instructions in this portal are written for HEC-HMS 4.x. Small differences in menu wording between versions are normal — if a menu item is not exactly where the instructions say, look in the **Components** and **GIS** menus, or right-click the item in the Watershed Explorer.

## QGIS

Install the **Long Term Release (LTR)** from qgis.org. After installing, check that you can add an OpenStreetMap basemap: in the Browser panel expand *XYZ Tiles* and double-click *OpenStreetMap*.

## HEC-RAS (from Unit IV)

HEC-RAS 6.x runs only on **Windows**. If your laptop is a Mac or runs Linux, plan to use the department computer lab for Sessions 28–36, or a Windows virtual machine. Install the example projects when prompted (or via *Help › Install Example Projects*).

## Course data

All datasets used in class are in the `data/` folder of this portal and are linked from the session that uses them. Teaching datasets marked *synthetic* are made up for practice; your PBL project must use real data from IMD, India-WRIS, KSNDMC or CGWB, cited with source and download date.

## Getting help

1. Read the **Message Log** in HEC-HMS — it usually names the problem.
2. Go through the lab's steps again — use **Show all steps** to see the whole sequence at once.
3. Post the error message and a screenshot in the Google Classroom stream.
